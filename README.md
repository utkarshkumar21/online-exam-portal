# Online Examination Portal

A front-end web application simulating an online exam with multiple-choice questions.

## Tech Stack
- HTML, CSS, JavaScript
- MySQL (optional backend)
- Concepts: CRUD, dynamic UI, API simulation

## Features
- Display multiple-choice questions
- User can select answers and submit
- Score calculated dynamically
- Clean and responsive interface

## How to Run
1. Clone the repository
2. Open `client/index.html` in a browser
3. Attempt the exam and click submit to see results
